Redesign the web app's look and feel.

- New stage-and-tile palette with a box-orange accent, Bricolage Grotesque headings, an ink header with a sneaker app mark and favicon, and a split-screen sign in and sign up.
- The collection page now opens with a one-sentence summary and a single filter toolbar above borderless shoe tiles.
- Grails, activity, sneaker detail and the add and edit forms follow the same style.
- Also adds a 404 page, a skip-to-content link, a keyboard-accessible add mode switch, and sentence-case condition labels, and keeps the current results on screen while filters load.
- Removes the per-brand badge colours.
